# Covaverse Japan Journeys

เว็บตัวอย่างทัวร์ญี่ปุ่นแบบ 3 มิติ สร้างด้วย Three.js เป็นหน้าเดโมสำหรับนำเสนอ ไม่มีการจองหรือชำระเงินจริง

## มีอะไรบ้าง

1. **เรื่องเล่าแบบเลื่อนหน้า (scroll story)** กล้องเคลื่อนต่อเนื่องในโลก 3 มิติเดียว ไม่มีการตัดฉาก
   สนามบินสุวรรณภูมิ → เทคออฟ → เส้นทางบินเหนือเมฆ → ลงจอดนาริตะ → พบไกด์และรถทัวร์ → อุโมงค์โทริอิ เจดีย์ชูเรโตะ ฟูจิ → โรงแรม
   เวลาในฉากเปลี่ยนจากรุ่งเช้า กลางวัน พระอาทิตย์ตก จนถึงกลางคืน
2. **ชมก่อนจอง** เลือกดูโรงแรม ห้องสวีท เรียวกัง และสถานที่เที่ยว กล้องจะบินไปยังจุดนั้นโดยตรง
3. **จัดทัวร์เอง** เลือกสนามบิน สถานที่ ที่พัก ประกัน และบริการเสริม แผนที่โฮโลแกรมจะแสดงเส้นทางบินและเส้นทางรถ พร้อมราคาประเมินและแผนรายวัน
4. **บริการครบวงจร** ตัวอย่างหน้าประกันการเดินทาง และหน้าติดตามสถานะทริป (เดโม)

Visual FX: bloom, กลีบซากุระร่วง, เมฆ, ควันจากออนเซ็น, ไฟกลางคืน, vignette และ film grain
โมเดลทั้งหมดสร้างด้วยโค้ด ไม่มีไฟล์โมเดลที่ต้องซื้อ

## รันบนเครื่อง

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # ได้โฟลเดอร์ dist/
```

Push ขึ้น `main` แล้ว GitHub Actions จะ deploy ไป GitHub Pages ให้อัตโนมัติ
(เปิดครั้งแรกที่ Settings → Pages → Source: GitHub Actions)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/main.js` | renderer, post-processing, การคำนวณกล้องจาก scroll และการบินระหว่างจุด |
| `src/world.js` | วางฉากทั้งหมดในโลกเดียว, keyframe ของกล้อง, เวลาในฉาก |
| `src/models.js` | โมเดลแบบ procedural: เครื่องบิน รถบัส โทริอิ เจดีย์ ฟูจิ โรงแรม เรียวกัง |
| `src/fx.js` | ท้องฟ้า เมฆ ซากุระ contrail และ film shader |
| `src/mapholo.js` | แผนที่โฮโลแกรมและเส้นทาง |
| `src/builder.js` | ฟอร์มจัดทัวร์และการคำนวณราคา (ตัวอย่าง) |
| `src/data.js` | ข้อมูลสนามบิน สถานที่ โรงแรม ประกัน |
